Les Controleurs

Dans l’architecture MVC les contrôleurs sont la partie communicante avec le serveur.
Ils sont assez simples à utiliser car il ne nécessite l’utilisation que d’une simple fonction dans laquelle l'entièreté de vôtre code sera écrit. Par défaut vous devrez retourner un objet avec tous les éléments que vous voulez afficher dans vôtre vue.
